# Hyprland-config
Here is where i store my hyprland config files

# Installation
## Dependencies
This config requires:
`elephant` 
`snappy-switcher`
`hyprbars`
you can install everything with this command:
```
yay -S elephant snappy-switcher ; hyprpm update && hyprpm add https://github.com/hyprwm/hyprland-plugins && hyprpm enable hyprbars
```
## Download and install
1. Download the repo
``` 
git clone https://github.com/felixgamer27/Hyprland-config.git
```
2. Copy both folders to `~/.config`
3. Log out, then log in (or reboot)
